evalculist

evalculist evaluates JavaScript expressions in a sandboxed way without exposing global variables. It transforms variable references into function calls you control.

How It Works

evalculist transforms expressions by replacing:

  • foo → variable("foo")
  • foo.bar → dotAccessor(variable("foo"), "bar")
  • foo["bar"] → bracketAccessor(variable("foo"), "bar")
  • foo = value → assignment("foo", value)

You provide handler functions that control how each operation behaves.
